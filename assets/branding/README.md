# Ochi Artwork

`original.png` preserves the original user-supplied artwork. It is the source for
the Ochi launcher and browser icons, not a substitute for provider/account icons
or an instruction to introduce mascot UI.

The artwork was supplied for use in Ochi. Its permission for unrelated reuse or
redistribution under a software open-source license has not been established.
Do not assume that a future repository license automatically licenses this
artwork or its derivatives. Resolve these terms before public distribution.

`scripts/generate-icons.py` performs only image resampling, platform framing and
mask previews. It keeps the original composition and bytes intact. Generated
QA contact sheets/manifests are local build products, not assets to commit.
